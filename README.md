# LAPZONE Toolbox

Tải LAPZONE Toolbox cho Windows tại [Releases](https://github.com/Tunaa-11342/Lapzone-ToolBox/releases/latest).

- **x64** dành cho máy Intel hoặc AMD.
- **ARM64** dành cho máy Windows on Arm.

Nếu đang dùng bản cũ, hãy chép đè EXE trên máy hoặc USB một lần bằng bản từ v1.1.0. Các bản từ v1.1.0 kiểm tra cập nhật khi mở. Nếu có bản mới, bạn có thể chờ cập nhật hoặc chọn **Dùng bản hiện tại**.
